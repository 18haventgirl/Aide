# 医疗查询合同与急症语言变体修复

日期：2026-10-10。继 `205f5e4` 的首次评测后，分别处理紧急元数据漏检与离线合同差异。

## 改动

- `medical/chat.py` 补充讲话/言语、脸部字序、单侧胳膊、头痛前置和口语“反复吐”等变体。增加简单明确否定检查，同时保持其他肯定风险信号有效；不将其包装为完整医学分类器或诊断功能。
- `medical/evaluate.py` 的追问输入改用实际 MCP 工具的 `contextual_facts_query`。明确用户事实最多取 500 字，问题规范空白；完整输入先过范围检查，再把检索文本限制到 1000 字。避免仅识别“那…”开头的旧规则，也避免长问题的临床决策请求被截掉后放行。
- `suite_v3.json` 将原 80 题标为 `chinese-general-regression`，保留原题、标签和哈希。评测输出注明 `explicit_user_facts_v1` 合同；未知合同拒绝运行。原 v2 和首次结果保留。

语言变体对应现有急症提示范畴。参考国家卫健委[卒中宣传核心信息](https://www.nhc.gov.cn/ylyjs/zcwj/202210/07a1b6550af3423f930e73f7148df988.shtml)中的面部、手臂与言语识别，以及[2025-01-17 发布会](https://www.nhc.gov.cn/xcs/c100122/202501/4c0f023143ae4fd39b1a0339dd6bdecb.shtml)的严重头痛、频繁呕吐等就医提示。此次搜索可见相关官方摘要，但全文请求返回 412；没有把这两页作为新资料采集入库，也没有新增治疗建议。现有模型提示词仍独立负责问答中的风险识别。
