## 首次结果

Recall/MRR/nDCG 的分母是 64 道 supported 题；追问另外计算。无答案拒绝表示检索没有返回候选，不表示 LLM 拒绝回答。紧急表述指标仅检查本地规则，没有执行真实 Agent 急诊建议流程。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 关键词 | 1.000 | .977 | .983 | 1/8 | 2/4 | 1.16 ms |
| 纯 BGE | .938 | .922 | .926 | 7/8 | 2/4 | 37.49 ms |

所有模式紧急规则均只识别 2/4。重排 76 次全部 `applied`，4 道紧急题不执行检索；不存在重排失败却当作成功的统计。P95 为函数内耗时，包含本组无答案查询；不含 HTTP 或 LLM，不能与生产 batch 8 端到端耗时直接比较。

## 发现与处理顺序

1. **紧急表述规则存在漏检。** CGU02 的“讲话含糊 / 脸也歪了 / 一只胳膊抬不起来”和 CGU03 的“头痛突然特别剧烈 / 一直吐”超出旧正则字序。这是工具附加 urgency 元数据的问题；模型提示词仍有独立紧急就医要求，不能把本指标解释为模型实际只处理了 50% 的急症。先修复通用语言变体，并增加否定/历史叙述反例。
2. **离线追问与实际工具契约不一致。** 离线 `contextual_query` 只认短句开头，CGF02“已经…”与 CGF04“原来的…”未拼前文；实际工具使用显式 `prior_user_facts` 的 `contextual_facts_query`。后续评测应按工具实际输入合同拼接明确用户事实，并记录合同版本；不能只靠扩大“那…”关键词冒充上下文能力。
3. **重排在绝对阈值处误过滤。** CGS024 防鼠卫生、CGS035 职业防护否定问法、CGS042 果蔬和果汁替代均被返回空，最高重排分数分别 .015227 / .023082 / .009760，低于 .05 门槛。混合检索三题均命中。这同时提示通用 reranker 的语料适配和门槛问题。保留现有门槛，先用独立开发题测试批次/候选和校准方案；避免按这三题直接调阈值。
4. **无答案和正例之间存在取舍。** 混合检索误召回“血型与星座”“戒烟补贴申请”；重排过滤了它们，同时损失三个正例。不能根据这一小组宣称重排全面更优，暂不移除重排。
5. **规模与覆盖仍不足。** 新题主要检查已有健康素养文章，尚未新增深入医疗知识；120 道新开发题、40 道流程题、答案要点/证据断言及外部未见集仍待完成，后续和 M3 资料升级配套推进。

这组被用于修复或调参后应在新 suite 中标为回归组；原 `suite_v2` 和首次结果保留作为历史封存证据，不再声称后续数字来自未见测试。

续轮使用 `suite_v3.json`、`chinese-general-regression` 和 `explicit_user_facts_v1` 合同。原标签/哈希保持不变；跟首次合同不同的追问数字单独呈现，不直接归因于模型优化。

## 本轮验证

专项契约测试 11 项通过：固定标签、哈希/数量、Top K 指标、来源变化、缺损来源绑定、禁止覆盖和模式比较。最初两项报错来自 Windows 沙箱临时目录写入权限；设置 TMP/TEMP 为工作区 `logs/evaluation-test-tmp` 后正常执行，没有放宽业务校验。

此轮没有修改在线检索参数，没有新增医学结论，也没有完成答案级评估。
