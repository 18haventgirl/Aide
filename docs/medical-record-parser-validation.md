# 病历解析第一版验证记录

## 全部文件格式补测（2026-10-14 完成）

本轮使用同一份明确标注为虚构的中文门诊病历生成真实文件，样例就诊日期固定为 2026-10-09。TXT、DOCX 浏览器流程于 2026-10-10 完成，其余格式及最终数据库核验于 2026-10-14 完成。未使用真实患者资料。测试目标为：文件上传 → 实际解码/OCR → 模型解析 → 原文核对 → 人工修正 → 保存 → 刷新并从最近记录重开。

| 文件类型 | 实际读取方式 | 自动接口矩阵 | 真实模型浏览器完整流程 | 原件预览 |
| --- | --- | --- | --- | --- |
| UTF-8 BOM TXT | `text` | 通过 | 通过 | 展示提取原文 |
| DOCX（包含表格） | `docx` | 通过 | 通过 | 展示提取原文 |
| 文字 PDF | `pdf` | 通过 | 通过 | 中文页面正常显示 |
| PNG | `ocr` | 通过 | 通过 | 图片加载成功 |
| JPG | `ocr` | 通过 | 通过 | 图片加载成功 |
| JPEG | `ocr` | 通过 | 通过 | 图片加载成功 |
| 扫描 PDF | `ocr` | 通过 | 通过 | 扫描页面正常显示 |
| 混合 PDF（文字页 + 扫描页） | `pdf` + `ocr` | 通过 | 通过 | 两页正常显示，上一页/下一页通过 |

“通过”表示格式处理及上述操作流程通过，不表示每个字符都识别正确。所有样本均核对姓名、就诊日期、青霉素过敏、诊断“待排”、现病史“否认胸痛”、既往史“否认高血压”。点击原文依据后把姓名改为“周示例（已核对）”；刷新重开后，修正值和记录日期保留，字段为只读状态。

- 真实浏览器流程使用已有配置的 `deepseek-flash`，8 类均完成保存和重开。
- 对独立预览数据库只读核验：8 份已确认解析分别关联 8 条不同的健康记录；原始姓名、人工修正姓名、就诊日期、原文引用、读取方式及健康记录归属均正确。混合 PDF 保留第 1、2 页且同时包含 `pdf`、`ocr` 来源。
- 浏览器「个人数据 → 身体状况」的 2026-10-09 显示 8 条记录，逐条摘要保留原文诊断“待排”；截图为 `logs/parser-format-matrix/eight-health-records.jpg`。

- `tsc -b --noEmit` 和 Vite 生产构建通过；确认产物包含 PDF worker、CMap、字体和 WASM。保留既有 Browserslist 数据过期、API 模块混合导入警告。

本地证据位于忽略的 `logs/parser-format-matrix/`：`manifest.json`、`browser-results.json`、`database-verification.json`、PDF 预览截图；回归输出为 `logs/parser-format-regression.log`。预览数据库保留了修复前的两份文字 PDF 待核对草稿，没有为它们创建健康记录。

### 补测发现并修复

1. 内置浏览器的原生 PDF iframe 预览为空白。改用按需加载的 PDF.js，在页面内渲染，并提供翻页和下载入口。文字、扫描和混合 PDF 均已实际显示，混合 PDF 双向翻页通过。依赖与静态资源同站点提供，原文件仍仅保留在当前页面内存中。实现参考 [PDF.js 官方示例](https://mozilla.github.io/pdf.js/examples/)。
2. 模型偶尔把“姓名：”“就诊日期：”一起填入基础字段。现在移除基础字段精确匹配的标签前缀，随后仍执行原文依据校验；临床文本和限定词不做这种清理。新增回归并完成真实 PDF 重测。

### 仍需人工核对的质量边界

- PNG/JPG/JPEG 样本把 `36.7℃` 识别为 `36.7C`；扫描 PDF 识别为 `36.7°℃`。本轮明确保留为 OCR 质量发现，未用规则擅自补正医学单位，也未宣称字符级准确率为 100%。页面仍显示 OCR 核对提示，使用者应在确认前核对并修正。
- 当前中文 PDF 正常可读；PDF.js 对样例未嵌入的 STSong 字体产生系统字体回退警告，未验证所有机器上的字形一致性。
- 浏览器仍记录到聊天 WebSocket 重连错误。本轮病历 HTTP 流程全部完成，不把这个结论扩展到聊天服务。
- 真实脱敏病历、手写、模糊/倾斜照片、复杂多栏排版的识别质量仍未评估。

## 已修正的实测问题

- PDFium 4.30 的文档对象不支持直接作为上下文管理器，改为 `contextlib.closing`，扫描 PDF 实测通过。
- Dashboard 的动画背景覆盖了普通层级的解析界面，给解析工作区建立独立层级后重新截图检查。
- API 与旧 Agent 会话适配器可能使用不同事件循环，解析容量限制使用线程安全信号量，并增加跨循环验证。
