# Aide 界面规范

## 导航与布局

- 桌面使用 216px 深色侧栏，四个入口固定为智能对话、病历解析、个人数据、智能体。
- 手机使用相同四个入口的底部导航；不再叠加第二套侧栏导航。
- 顶部展示当前工作区与真实聊天连接状态。病历解析通过 HTTP 独立工作。
- 页面标题统一使用 `WorkspaceHeader`。桌面显示说明，窄屏保留紧凑标题与操作。
- 工作区使用 `100dvh`，内容区域独立滚动；320px 起可用。

## 视觉语言

- 浅灰背景、白色卡片、深色正文、蓝色主操作。红色仅用于错误与删除，琥珀色用于待核对提示。
- 颜色统一维护在 `ui/src/index.css` 的语义变量中。
- 卡片使用 `surface-card`，输入使用 `field-control`，操作按钮使用 `Button`。
- 登录页、加载页与导航共用 `AppLogo`。
- 使用系统中英文字体栈，不请求外部字体；无大面积渐变与背景漂移动画。
- 保留键盘焦点样式，并尊重 `prefers-reduced-motion`。

## 病历解析

- 导入页包含三步流程、文件/文字入口、虚构样例与数据处理说明。
- 核对页桌面双栏对照原文与字段，手机按顺序纵向滚动。
- 姓名、年龄、机构、日期等短字段用单行输入；就诊经过等长字段用多行输入。
- 原文依据保持可定位；切换到聊天后再返回仍保留尚未保存的字段修改。
- 保存按钮与归属日期固定在底部，沿用原有显式确认后保存的行为。
- 新建、切换有修改的记录、删除解析记录使用 `ConfirmDialog`。基于 HTML dialog 的页面内确认支持焦点约束与 Escape 取消，避免阻塞浏览器的原生 confirm。

## 个人数据与智能体

- 笔记、待办、身体状况共用数据页标题与分类导航。
- 健康日历在宽屏下与当天记录并排，窄屏纵向展示。
- 智能体状态、上下文与运行输出使用统一可折叠卡片；暂无任务时显示真实空状态。

## 本轮验证

- TypeScript 类型检查与 Vite 生产构建通过。
- 浏览器实查桌面页面，以及 390px、320px 手机布局，未发现横向溢出。
- 使用既有虚构病历验证历史记录打开、字段修改、页面切换保留修改、依据高亮与新建确认/取消。
- 检查笔记和待办的新建表单、健康日历和智能体空状态。
- 登录页在桌面与 320px 下实查，测试账号可正常登录回工作区。
